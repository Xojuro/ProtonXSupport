About

Once enabled, ProtonX monitors your server's audit log in real time. If a non-whitelisted user performs a dangerous action, their roles are stripped and they're immediately kicked, then the action they took gets reverted.

Setup requirement: Make sure the ProtonX role is placed at the very top of your role hierarchy, above all other roles. Give ProtonX all permissions, Administrator is recommended, so it can properly monitor, punish, and revert any nuke attempts without restriction.

Detected actions: creating/deleting channels or roles, granting dangerous permissions, banning/kicking members, changing the server name or icon, and creating webhooks. Per-permission whitelisting is also available for trusted mods.

Command list

Prefix: !x

Main command
!xhelp
Shows the full, up-to-date command list right inside Discord. Start here.
Anti-raid
!xanti-on / off
Turns the server's anti-nuke protection on or off.
!xalink-on / off
Configures anti-link protection (Discord invites, image links, all links).
!xalinkbypass
Choose categories that are bypassed by anti-link.
!xaspam-on / off
Configures the anti-spam threshold and timeout duration.
Moderation
!xautorole
Sets a role to be automatically given to new members.
!xlogs
Configures message, profile, voice, and member logs.
!xrole
Gives or removes a role from a member.
!xunwhitelist
Removes a user from the whitelist.
!xvc
Sets up join-to-create voice channels.
!xwhitelist
Whitelists a user for specific anti-nuke permissions.
!xwipe
Bulk-deletes messages in a channel.
!xwlist
Shows the list of whitelisted users.
Utility
!xafk
Sets an AFK status with a reason.
!xafklist
Shows who is currently AFK.
!xav
Shows a user's avatar.
!xbanner
Shows a user's profile banner.
!xbot
Information about ProtonX itself.
!xemojis / !xstickers
Lists the server's custom emojis or stickers.
!xinfo
Shows server details (members, roles, boosts, and more).
!xrolelist
Lists all of the server's roles.

8/7/26
!xalink-on/off
enables anti-link protection against any link attempt, including Discord invites, image links, and other URLs. Users with the Bypass Anti-Link permission are not affected. Use !xalinkbypass to select a category to bypass, and !xwhitelist to grant users the bypass link permission.
!xaspam-on/off
enables anti-spam protection with customizable settings. Choose the message threshold and timeout duration for detected spammers.
!xemojis
Shows all server emojis with their images and names.
!xstickers
Shows all server stickers with their images and names.
!xautorole
Sets a role to be automatically given to new members. Use !xautorole off to disable.
